# 현재 구현 점검 결과

## 범위

미커밋 변경을 포함한 현재 작업 트리를 기준으로 입력·주행·고속 점프·충돌·장애물 6종·랜드마크·기록 저장·메뉴 수명 주기·BGM·모바일 배치를 검토했다. 기존 기능을 바꾸는 추가 수정이 필요한 결함은 이번 점검에서 발견하지 못했다. 검증 결과는 확인한 환경과 시나리오에 한정한다.

## 자동 검사와 빌드

| 검사 | 결과 |
| --- | --- |
| `pnpm test` | 92개 통과, 실패 0개 |
| `pnpm lint` | 통과 |
| `pnpm exec tsc --noEmit` | 통과 |
| `pnpm build` | 실행 환경의 Turbopack 보조 프로세스 포트 바인딩 권한 오류로 중단 |
| `pnpm build --webpack` | 프로덕션 빌드 및 정적 페이지 생성 성공 |
| Webpack 빌드의 `pnpm start` | 실행 성공, 실제 브라우저 검증 완료 |

기본 빌드 실패는 `globals.css`의 PostCSS 처리 과정에서 보조 프로세스가 포트를 열 때 발생한 `Operation not permitted (os error 1)`이다. 권한을 확장한 실행에서도 같은 결과였다. 이를 게임 로직 오류로 분류하거나 실제 배포 환경의 기본 빌드 성공을 보장하지 않는다. 현재 검증 환경에서는 `pnpm build --webpack`을 사용한다. 이 제한을 피하려고 패키지 버전이나 기본 빌드 설정을 변경하지 않았다.

## 코드와 테스트 확인

- 점프 시간은 30m/s까지 0.8초, 이후 최대 이동 거리 24m에 맞춰 줄어든다. 최대 높이 유지, 공중 가감속, 한 프레임 안에서 끝나는 점프와 착지 후 충돌을 확인했다.
- 6종 장애물의 단일 점프 회피는 14~1022m/s, 20/30/60/144 FPS 조합으로 검사한다. 최소 35m 간격의 연속 3개 행 재점프, 너무 늦은 점프, 구멍 안 착지도 포함한다.
- 장애물 종류 순환, 1칸/2칸 배치, 안전 구간, 긴 주행에서의 활성 오브젝트 수, 이동량이 큰 프레임의 충돌 누락 방지를 검사한다.
- 랜드마크 10종의 10~100km 배치, 접근 안전 구간, 정확한 도착, 2.5초 축하, 재출발과 마지막 랜드마크 이후 진행을 검사한다.
- 메뉴의 동적 Phaser 로드와 해제, 이벤트·입력·ResizeObserver 정리, 단일 audio 요소, 재도전 시 BGM 초기화 연결을 검토했다.
- localStorage 미지원·손상·쓰기 실패 시 게임이 중단되지 않는지, 이전 최고 기록 유지와 평균 속도 계산이 맞는지 검사한다.
- 이미지 16종의 실제 파일·프레임 범위와 사용 중인 BGM 파일 존재 검사가 통과했다. 변경된 이미지 폴더 경로도 반영되어 있다.

## 프로덕션 브라우저 확인

- 첫 방문 BGM 선택 전에는 캔버스 0개, 오디오는 muted/paused 상태였다. 무음 선택 후 새로고침해도 설정이 유지되고 선택 창은 다시 나타나지 않았다.
- 메뉴 → 클래식 → 가속·점프 → 일시정지 → 메뉴를 3회 반복했다. 게임에서는 캔버스 1개, 메뉴에서는 0개, audio는 항상 1개였다. 매번 가속 입력 한 번에 14→22m/s로 변경됐다.
- 390×844 세로 화면에서 가로 회전, 터치 가속·점프, 게임오버·재도전, 일시정지를 확인했다. 페이지와 일시정지 창 모두 가로·세로 스크롤이 없었다.
- 1024×320 가로 화면에서 게임은 약 746.66×320으로 21:9를 유지하고, 패드는 화면 좌우 12px 위치까지 배치됐다. 오른손 점프와 감속도 작동했다.
- 320×360에서 일시정지 창의 높이와 scrollHeight는 246px로 같았다. 계속하기·메인 메뉴는 같은 행에 배치됐다.
- 일시정지 중 BGM을 켜도 재생은 정지 상태를 유지했고, 계속하기 후 재생됐다.
- 검증 구간의 브라우저 console error/warning은 없었다. 검증용 서버와 탭을 정리했으며 기존 개발 서버의 설정은 변경하지 않았다.

## 검증 한계

실물 모바일 기기의 멀티터치·노치, 실제 Xbox/PS 패드, 개별 Chrome/Edge/Safari/Firefox 배포 환경은 이번 점검에서 직접 검증하지 않았다. 모바일은 브라우저 뷰포트·버튼 조작, 패드와 멀티터치는 모의 입력 테스트로 확인했다. BGM은 실제 청취 대신 재생 상태·재생 위치와 로드 여부를 확인했다. 기본 Turbopack 빌드는 위 실행 환경 제한 때문에 완료 여부를 확인할 수 없다.
